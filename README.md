# Тема WordPress: Medio (для стоматологии)

Кастомная тема WordPress, разработанная с нуля для демонстрационного медицинского проекта.

## 🛠 Стек технологий

- WordPress (Custom Theme)
- PHP 8.1+
- HTML5 / CSS3 (Mobile-First)
- JavaScript (Vanilla JS для AJAX-форм)
- Bootstrap 5
- Secure Custom Fields (SCF)
- Git

## ✨ Основные фичи

- **CPT:** Услуги, Врачи, Отзывы.
- **AJAX-формы:** Отправка заявок в Telegram + почта, валидация, nonce.
- **Безопасность:** Экранирование (`esc_html`, `esc_url`), CSRF-защита.
- **Legal:** Политика конфиденциальности (152-ФЗ) и Лицензии (с QR-кодом по 118н).
- **Cookie-баннер:** Свой код.
- **Адаптив:** Mobile-First.
